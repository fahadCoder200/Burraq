# Burraq
I'll update this later, but I want to build a multi-threaded Rust powered CPU engine that handles pre-processing, caching and memory transfers. Let's see where this initiative leads!

Why is it named "Burraq", in Islamic tradition Al-Buraq is a supernatural, celestial steed sent from the heavens. It is most famous for serving as the mount that carried the Prophet Muhammad during the miraculous Isra and Mi'raj (the Night Journey and Ascension).
The name itself is derived from the Arabic word barq, which translates directly to "lightning," reflecting its blinding speed and radiant nature! 
So Burraq is a reference to its high speed capabilities and blazingly fast pre-processing capabilities.
